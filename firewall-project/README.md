# 🔒 سپر — فایروال کوکی و شبکه

پروژه‌ای سه‌بخشی برای محافظت شخصی از کوکی‌های ردیاب و درخواست‌های شبکه‌ی مزاحم:

- **Backend** (`backend/`) — موتور قوانین به زبان پایتون (Flask)
- **Dashboard** (`dashboard/`) — پنل وب برای مدیریت قوانین و دیدن رویدادهای زنده
- **Extension** (`extension/`) — اکستنشن کروم/فایرفاکس که واقعاً کوکی و درخواست‌ها را بلاک می‌کند

همه‌چیز **کاملاً محلی** اجرا می‌شود (`127.0.0.1`) — هیچ داده‌ای به سرور خارجی فرستاده نمی‌شود.

---

## ۱. راه‌اندازی بک‌اند

```bash
cd backend
pip install -r requirements.txt
python3 app.py
```

اولین بار که اجرا می‌کنید، یک **کلید API** در ترمینال چاپ می‌شود:

```
API Key شما (آن را در اکستنشن و داشبورد وارد کنید):
  xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

این کلید را کپی کنید — هم برای داشبورد هم برای اکستنشن لازم است.
سرور روی `http://127.0.0.1:5000` بالا می‌آید.

> کلید به‌صورت خودکار در `backend/logs/.api_key` هم ذخیره می‌شود.

---

## ۲. داشبورد وب

داشبورد همراه با بک‌اند serve می‌شود. کافی است در مرورگر باز کنید:

```
http://127.0.0.1:5000
```

کلید API را وارد کنید تا متصل شوید. از اینجا می‌توانید:
- قوانین جدید (allow/block) برای کوکی یا شبکه اضافه کنید
- قوانین را فعال/غیرفعال یا حذف کنید
- رویدادهای زنده‌ی بلاک‌شده را روی رادار ببینید

---

## ۳. نصب اکستنشن مرورگر (Chrome)

1. به آدرس `chrome://extensions` بروید
2. گزینه‌ی **حالت توسعه‌دهنده (Developer mode)** را فعال کنید
3. روی **بار کردن بسته‌نشده (Load unpacked)** کلیک کنید
4. پوشه‌ی `extension/` را انتخاب کنید
5. روی آیکون سپر کلیک کنید و کلید API را وارد کنید

اکستنشن از این لحظه:
- هر کوکی جدید را با بک‌اند چک می‌کند و در صورت تطبیق با قانون بلاک، آن را فوراً حذف می‌کند
- قوانین شبکه را هر ۳۰ ثانیه از بک‌اند می‌گیرد و با `declarativeNetRequest` (روش امن و رسمی مرورگر) اعمال می‌کند

---

## نکات امنیتی

- تمام endpoint های حساس پشت **API Key** هستند (هدر `X-API-Key`)
- **Rate limiting** روی تمام درخواست‌ها فعال است (۱۲۰ درخواست در دقیقه)
- ورودی الگوهای قانون (pattern) قبل از ذخیره **پاک‌سازی (sanitize)** می‌شوند
- CORS فقط به `localhost` و اکستنشن‌های مرورگر محدود است، نه باز برای همه
- در صورت قطع ارتباط با بک‌اند، اکستنشن **fail-open** عمل می‌کند تا مرورگرتان قفل نشود (یعنی کوکی‌ها بلاک نمی‌شوند، اما قوانین شبکه‌ی از‌پیش‌اعمال‌شده فعال می‌مانند)
